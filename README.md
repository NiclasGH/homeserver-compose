# Pi Compose
This is my raspberri pi in a docker compose file.
The root compose is the "root" compose with the main services. Submodules are in other folders.

## Domains
* `media.tira-misu.org`: Jellyfish
* `dns.tira-misu.org`: Pihole
* `id.tira-misu.org`: Keycloak
* `kuma.tira-misu.org`: Uptime-Kuma
* `filebrowser.tira-misu.org`: Filebrowser
* `torrent.tira-misu.org`: QBitTorrent Client
* `movies.tira-misu.org`: Sonarr to download movies
* `shows.tira-misu.org`: Radarr to download shows
