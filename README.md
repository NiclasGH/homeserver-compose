# Pi Compose
This is my raspberri pi in a docker compose file.
The root compose is the "root" compose with the main services. Submodules are in other folders.

## Port Exploration:
Public Services will use 8000+:
* 8000: Jellyfish
* 8001: Pihole
* 8002: Keycloak
* 8003: Uptime-Kuma
* 8004: Filebrowser
